    📘 ヘルプ

    📖 SRC Portalについて

    SRCメンバーのラン＆ウォークやフィットネスへの参加予定を共有し、仲間と楽しく運動を続けるためのアプリです。

    📋 使い方

    1. 現在のユーザーを選択します。
    2. 「ラン＆ウォーク」または「フィットネス」を選択します。
    3. 参加したい日付をタップします。
    4. ラン＆ウォークは「参加する」、フィットネスはQUESTを選択して参加登録します。登録後は必要に応じて「参加取消」を押せます。

    参加人数や参加者はリアルタイムで更新されます。ダッシュボードの「次回イベント」をタップすると、該当月のカレンダーへ移動します。

    今日または明日に参加予定がある場合は、「あなたの次回参加予定」のタイトルと背景色が変わり、予定を目立たせて表示します。参加予定のイベントは名称・日時・場所を表示します。未回答のイベントや、ほかのメンバーが参加登録している翌日のフィットネスがある場合は、別途リマインダーで参加登録を案内します。

    📈 シーズン活動記録

    上期（4～9月）・下期（10～3月）ごとに、自分のラン＆ウォークとフィットネスの参加回数を確認できます。トップ画面には今期の回数を表示し、カードをタップすると前期との比較やチームの参考値を確認できます。

    増加した場合は少し強調し、同じ場合は穏やかに表示します。減少した場合は評価せず、回数の事実だけを表示します。ラン＆ウォークとフィットネスの個人順位は表示しません。

    ラン＆ウォークには通常活動・大会・駅伝を含みます。中止イベントと「行けなくなりました」は集計から除外します。フィットネスは実際に参加登録が残っている日を実績として集計します。

    🏋️ フィットネスの参加・GYM QUEST

    フィットネストレーニングは定期開催ではありません。行きたいメンバーがカレンダーから参加を表明すると、その日が「次回フィットネス開催候補」として共有されます。基本の開始時刻は19:00です。

    トップ画面の「GYM QUEST」カードでは、次回フィットネス開催候補、参加人数、補助対象までの人数、自分が選んだQUESTを確認できます。カード本体をタップするとフィットネスのカレンダーへ移動します。

    🎮 GYM QUESTの参加方法

    1. フィットネスのカレンダーで参加したい日を選びます。
    2. 最初の参加者は「フィットネス行きたい！」、すでに参加希望者がいる場合は「参加する」を押します。
    3. 「YOUR GYM QUEST」で好きなQUESTを1つ選びます。
    4. 「このQUESTで参加する」を押すと参加確定です。

    QUESTは、普段のトレーニングに小さな遊びを加えるための軽いチャレンジです。トレーニング開始前までは、トップ画面の「あなたのQUEST」にある「QUESTを変更 ＞」から選び直せます。

    トップ画面には「GYM QUEST Lv.」とXPもコンパクトに表示します。QUESTのクリアによるXP・レベル・称号・バッジなどの詳細な成長ルールは現在検討中です。

    🏆 FITNESS POINT

    FITNESS POINTは、フィットネスで取り組んだ内容を自分で記録し、シーズンごとの活動を振り返るためのポイントです。ポイント登録は本人の自己申告で行います。

    2026年度上期（4月1日～9月30日）は、景品を設定せず「活動記録」として運用します。 ランキングは競争を目的としたものではなく、みんなで楽しく運動を続けるための参考表示です。

    POINTのつき方

    • フィットネスに参加：+1pt
    • 有酸素運動を10分：+1pt
    • 柔軟・ストレッチ：+1pt
    • マシン：1台につき+1pt（最大3pt）
    • BONUS QUEST達成：+1～2pt

    1回のフィットネスで獲得できるPOINTは最大8ptです。実際に参加登録が残っている日の記録だけがシーズン集計の対象になります。

    POINTの記録方法

    1. フィットネスに参加登録します。
    2. トレーニング開始後、対象日の画面から「今日のPOINTを記録」を開きます。
    3. その日に行った有酸素・柔軟・マシン・QUEST達成を自分で入力します。
    4. 内容を確認して保存します。保存後も、自分の記録は必要に応じて修正できます。

    ランキングと自分の記録

    FITNESS POINTカードを開くと、シーズンのランキングと「自分の記録」を確認できます。同じPOINTの場合は同順位です。

    「自分の記録」では、今季POINT、フィットネス回数、QUEST達成回数、平均POINTに加えて、来館回数、有酸素運動、柔軟運動、マシン累計台数、QUEST達成回数、日ごとの活動履歴を確認できます。

    シーズンは上期（4～9月）・下期（10～3月）で区切ります。参加を取り消した日のPOINTは集計には含まれません。

    💰 ジムの料金・補助

    ジムは1人から利用できます。3人以上集まった場合は、ジム利用料300円／人をクラブ費から補助します。「開催決定」ではなく、3名以上になった時点で「補助対象」として表示します。

    • 登録カード料：初回のみ200円
    • ロッカー利用料：50円
    • ジム利用料：300円（3人以上でクラブ費補助）

    登録カード料とロッカー利用料は補助対象外です。サンフロッグ春日井の場所と休場日は、ジム画面のリンクから確認できます。

    📍 場所・休場日のリンク

    ラン＆ウォークの「落合公園」と、ジムの「サンフロッグ春日井」をタップすると地図を開きます。ジムの「休場日を確認」から施設カレンダーを確認できます。

    ラン＆ウォークの開催後は、イベント詳細の「🏃 今日の練習」でグループ別の距離・周回・ペースを確認できます。管理者は過去のイベントを含め、1グループ1行で入力・修正できます。

    📢 お知らせ

    管理者からの正式な連絡です。トップ画面では見出しを確認し、「お知らせ」をタップすると全件の詳細を表示できます。

    💬 みんなの伝言板

    トップ画面の「みんなの伝言板」カード、または☰メニューの「みんなの伝言板」から開けます。伝言と掲載期間（3日・7日・14日）を選んで投稿してください。自分の投稿は削除でき、管理者はすべての投稿を削除できます。期限切れの投稿は表示されません。

    ⭐ みんなのおすすめ

    トップ画面の「みんなのおすすめ」カード、または☰メニューの「みんなのおすすめ」から開けます。SRCメンバーがおすすめするコース・お店・大会・グッズなどを共有でき、カテゴリで絞り込み、「新着順」と「人気順」を切り替えられます。

    投稿項目はカテゴリ、タイトル、おすすめコメント、場所（任意）、リンク（任意）です。投稿者名と投稿日は自動表示され、写真は使用しません。自分の投稿は編集・削除でき、管理者はすべての投稿を削除できます。

    「👍 いいね」は1人1回押すことができ、もう一度押すと取り消せます。誰が押したかは表示せず、合計数だけを表示します。

    🗺 SRC-KYRO

    トップのSRC-KYRO-Clubカードから、クラブ全体の全国順位・愛知県順位・領土・最新ニュース・次の目標を確認できます。

    その下には、現在のユーザーがKYRO参加者の場合、2026/05/01からの個人累計として、累積走行距離、前回更新比、前回更新日、現在順位、最終更新日時を表示します。KYRO個人データが未取込の場合は表示されません。

    上部の「メンバー」または個人記録内の「全員の距離を見る」をタップすると、KYRO参加者全員の累積走行距離一覧と最終更新日時を確認できます。登録メンバー一覧では、KYROメンバーの名前の横に黄色の「KYRO」バッジが表示されます。

    🤖 AI連携（管理者）

    管理者メニューの「AI連携」から、KYROメンバー一覧のスクリーンショットをこのAIで読み取るための依頼文をコピーできます。AIが返した「KYROネーム,累積走行距離」のデータを貼り付け、内容を確認してからFirestoreへ反映します。

    取込前に、メンバー管理でKYRO参加をONにし、KYROネームを登録してください。取込時は未登録名、重複、数値不正、今回のデータに含まれないKYROメンバーを確認できます。順位は累積走行距離の多い順にSRC Portalが自動計算し、同じ距離は同順位になります。前回取込から順位が変動した場合は、一覧の順位横に「↑2」「↓1」のように変動幅を表示します。

    更新頻度は自由です。新しい日付で取り込むと、前回の距離と更新日を保存し、前回更新比を自動計算します。同じ取得日で再取込した場合は、前回データとして扱いません。

    🔐 招待コードとユーザー設定

    初回登録やユーザーの再設定では、管理者から案内された招待コードを入力してください。登録後は同じ端末で通常利用する限り、毎回の入力は不要です。招待コードは本人以外へ共有しないでください。

    👤 自己紹介

    登録メンバー一覧で名前をタップすると、そのメンバーの自己紹介を確認できます。自分の自己紹介を開いた場合だけ「自分の自己紹介を編集」ボタンが表示されます。

    必須項目：ニックネーム、ひとこと
    任意項目：所属、趣味・好きなこと、ランニング歴、ベストタイム、現在の目標

    ランニングをしていない方は、ランニング歴やベストタイムを空欄のまま登録できます。入力した自己紹介はほかの登録メンバーにも表示されます。

    自己紹介画面には、本人の今月のラン＆ウォーク回数とジム回数を表示します。KYRO参加者は、個人KYRO情報も確認できます。

    📄 利用規約

    SRC Portalをご利用いただきありがとうございます。

    みんなが気持ちよく利用できるよう、以下の内容をご確認ください。

    1. 利用できる人

    SRCメンバーとして管理者が登録した方が利用できます。

    2. 利用について

    • 参加登録・取消はご本人が行ってください。
    • みんなが気持ちよく利用できるよう、ご協力をお願いします。

    3. やってはいけないこと

    • 他人になりすまして利用すること
    • 他人の参加情報を勝手に変更すること
    • アプリの正常な運営を妨げること
    • その他、管理者が不適切と判断する行為

    4. 利用停止について

    次の場合は、管理者の判断で利用を停止（無効化）することがあります。

    • SRCメンバーでなくなった場合
    • 1年以上利用がない場合
    • 利用ルールを守っていただけない場合
    • その他、運営上必要と判断した場合

    再度利用したい場合は、管理者までお気軽にご連絡ください。

    5. アプリについて

    本アプリは、必要に応じて機能の追加・変更・停止を行うことがあります。

    6. 個人情報について

    アプリでは、運営に必要な範囲でメンバー名や参加情報などを管理します。

    取得した情報は、SRC Portalの運営以外の目的には利用しません。

    7. 利用規約の変更

    必要に応じて、本利用規約を変更する場合があります。

    🔒 プライバシーポリシー

    SRC Portalでは、運営に必要な範囲で次の情報を取り扱います。

    • メンバー名、管理者設定、招待・登録状況
    • イベントへの参加・取消・当日連絡
    • 登録日時、最終利用日時などの運用情報

    これらの情報は、参加予定の共有、開催判断、メンバー管理およびアプリ改善のために利用し、法令に基づく場合を除いて目的外で第三者へ提供しません。

    アプリ利用時には、Firebase Authenticationが匿名の識別番号（UID）を自動発行します。匿名認証のために、氏名やメールアドレスをFirebase Authenticationへ登録するものではありません。

    端末には、選択したユーザーや招待認証に必要な情報が保存される場合があります。共用端末では利用後の管理に注意してください。
